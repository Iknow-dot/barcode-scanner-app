What can a company admin customize?

Pick everything that should be in scope. We'll narrow later if needed.

A

Primary / accent color

Buttons, links, highlights — drives Ant Design's colorPrimary token.

B

Logo upload

Replace the default logo in the sidebar / header (light + dark variants).

C

Default theme (light/dark) for the org

Set what new users see by default. Individuals can still toggle per-session.

D

Full color palette

Primary + success/warning/error + neutral background. More control, more rope.

E

Typography

Font family, base size. Note: Georgian script needs a Georgian-compatible font.

F

Login page branding

Org logo + colors on login page (requires resolving org from subdomain or URL param — adds complexity).

G

Favicon / browser tab title

Per-org favicon and document title.

H

UI density / border radius

Compact vs comfortable, sharp vs round corners.
