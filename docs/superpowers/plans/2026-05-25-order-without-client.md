# Order without a client (retail order) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a consultant create and build an order with no client attached ("retail" order, flagged `is_retail`), shown everywhere as "Retail customer" / "საცალო მომხმარებელი".

**Architecture:** Add an `is_retail` boolean to `PurchaseOrder`. The serializer requires `customer_name` only for non-retail orders and blanks client fields for retail ones. The frontend `ClientLookupModal` gains a "Continue without client" action (new-order mode only); a shared `displayCustomerName` helper renders the localized retail label wherever `customer_name` is shown. The backend invoice token resolves the (Georgian-only) retail label.

**Tech Stack:** Django 6 + DRF (backend, `manage.py test`), React 18 + Ant Design + CRA/jest (frontend, `npm test`).

**Spec:** `docs/superpowers/specs/2026-05-25-order-without-client-design.md`

**Conventions for this plan:**
- All commits end with the repo trailer (shown via a second `-m`): `Co-Authored-By: Claude Opus 4.7 (1M context) <noreply@anthropic.com>`.
- Backend commands run from `backend/`; frontend commands from `barcode-scanner-frontend/`.
- The repo has **no React component-test harness** (only pure-function jest tests live in `src/utils/*.test.js` and `src/components/UserDashboard/*.test.js`). So we TDD the pure logic (backend + the `displayCustomerName` helper) and gate UI-wiring tasks with the production build (`npm run build`) rather than inventing brittle component tests.

```python
        is_retail = attrs.get('is_retail')
        if is_retail is None:
            is_retail = getattr(self.instance, 'is_retail', False)
        if is_retail:
            # Retail orders map to the 1C retail counterparty and carry no
            # client data — blank the client fields server-side so a stray
            # value from the request can't leak in.
            for field in (
                'customer_name', 'customer_phone',
                'customer_identification_number', 'external_client_id',
            ):
                attrs[field] = ''
        else:
            name = attrs.get('customer_name')
            if name is None:
                name = getattr(self.instance, 'customer_name', '')
            if not (name or '').strip():
                raise serializers.ValidationError(
                    {'customer_name': 'This field is required for non-retail orders.'}
                )
        return attrs
```

```javascript
// Resolves the customer label to show for an order. Retail (clientless) orders

const displayCustomerName = (order, t) => {
```
