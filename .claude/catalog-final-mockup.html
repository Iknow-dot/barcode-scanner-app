Final catalog design — all four states

The approved hybrid (Option A's rich rows + Option C's tile wall at root), exactly as specced: monograms instead of emoji on the tiles (1C category names can't be mapped to icons), count in the crumb header, full breadcrumb path only from depth 2, and a placeholder thumb wherever a photo is missing. Behavior is untouched — every screen below is the same drawer, same taps, same API calls.
